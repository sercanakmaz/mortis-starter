# Example slice

Whether a small worked example (an order and a product) is generated to copy from.

## example

Whether to generate the example slice.

**By preset:** lean `true`, standard `true`, advanced `false`.

### true

**Choose when:** you want a reference to copy; the first project.

**Costs:** files to delete later.

### false

**Choose when:** you know the structure and want a clean project.

**Costs:** no worked example to copy.

Example:

```
| Key | Value | Why |
| example | true |  |
```
